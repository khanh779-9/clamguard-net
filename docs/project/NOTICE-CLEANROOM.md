# Clean-Room Implementation Notice

ClamGuard.NET is implemented as original C# code with independently designed types, abstractions, control flow, storage structures, and APIs.

The project is not a source-code translation of ClamAV's C/C++ implementation. Compatibility targets are expressed as format and behavior contracts.

The repository does not include ClamAV source files, generated object files, or a copied implementation of ClamAV internals.
