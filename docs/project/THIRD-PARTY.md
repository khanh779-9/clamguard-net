# Third-Party and Compatibility Notes

ClamGuard.NET is an independent implementation intended to provide selected compatibility with ClamAV database formats and scanning behavior.

The repository does not redistribute ClamAV source code. The implementation uses .NET standard library APIs and original C# code.

Reference material was used to understand documented file formats and observable behavior. This repository should not be interpreted as a relicensing of ClamAV or its official signature databases.

Official ClamAV databases, YARA rules, and other external signature assets may carry separate terms and are not included in this repository.
